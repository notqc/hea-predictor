# HEA Hardness Prediction System (static web version)

The site is three files: `index.html`, `hea.js` and `model.json`. It needs no server and runs fully in the browser.

## Publish free on GitHub Pages
1. Create a public GitHub repository, for example `hea-hardness`.
2. Upload these three files to the root of the repository with Add file → Upload files, then Commit.
3. Go to Settings → Pages. Under Source, choose "Deploy from a branch", set the branch to `main` and the folder to `/ (root)`, then click Save.
4. After 1–2 minutes the site is live at: https://<your-github-username>.github.io/hea-hardness/

You can also drag this folder onto https://app.netlify.com/drop, which gives a link like `hea-hardness.netlify.app`.
